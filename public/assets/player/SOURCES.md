# Local resource provenance

Selected original PNGs copied from `Fantasy RPG Icons Pack` in the user-provided
reference folder. The pack filenames and category organization are recorded here;
descriptive runtime keys keep existing Character ability icon IDs compatible.
Runtime PNGs are downsampled to 128 × 128 for the action slots and high-DPI displays.

`frames/divider.png`: fantasy-ui-borders / PNG / Default / Divider / divider-000.png.
`utility/book.svg` and `utility/search.svg`: simple_icons / entity / book.svg and
simple_icons / util / search.svg. Utility art is tinted in CSS; gameplay slots use
the painted RPG pack.
BG3 screenshots are reference-only. No BG3 asset is included in this directory.
Pack ownership/licensing remains that of the supplied local resources.
RPG item icons: selected 1.png from the named local packs, PNG/without background, copied at 256px preserving aspect ratio; item_cloak currently shares armor art.
