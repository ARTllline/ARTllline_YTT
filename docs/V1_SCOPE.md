# V1 — feature freeze

Task 12 stabilizes the existing tabletop; it does not introduce another major system.

## Included

- Campaigns / Scenes; GM / Player invitations and permissions.
- Maps / Tokens / Props; manual Fog; Ruler / AoE / Ping.
- Combat, HP and conditions without rules adjudication.
- Asset Library, image Handouts, GM Notes, Prefabs and Encounters.
- Cue / Director; Audio / Atmosphere.
- Session Mode / Preload; Regions / Triggers.
- Russian UI: Сцена, Материалы, Игроки, Бой, События, Триггеры, Области,
  Заметки мастера, Столкновения, Заготовки, Сессии, Атмосфера, Звук.
- V1 refinements: GM marquee selection, bounded scene-edit undo/redo,
  selective handout sharing/revocation, operational diagnostics and deployment docs.

## Explicitly Post-V1

Dynamic LOS, walls, lighting, rules/dice engines, character builder, macros/DSL,
Story integration, voice/video, spatial audio, cloud storage integrations,
marketplace and plugin ecosystem. Also deferred: advanced automation graphs,
immutable combat archives, durable offline editing and full mobile authoring.

Release acceptance and evidence belong in V1_RELEASE_CHECKLIST.md and VALIDATION.md;
this scope is not itself a claim that acceptance has passed.
