# CONTENT-UX-02 — RPG Visual Polish

Проверено 12.11.2026. Изменения относятся к отображению Item/Spell Library.

## Интерфейс

- Адаптивный каталог: иконка, категория/школа, редкость/круг, две ключевые
  характеристики, происхождение и редакция правил. Редкость обозначена цветом
  и текстом; школа и круг также имеют текстовые подписи.
- До выбора записи каталог занимает всю ширину. Inspector появляется справа,
  имеет компактный заголовок с доступными действиями и независимую прокрутку на
  desktop. На mobile используется обычная прокрутка страницы, кнопка возврата
  возвращает фокус к выбранной карточке.
- Характеристики, поддерживаемые механики, описание и сведения источника
  разделены. Длинные названия полностью доступны в Inspector; сводки карточек
  ограничены двумя строками с полным текстом в title.
- Системные записи и личная коллекция сохранили явные текстовые обозначения.
  Личная коллекция предметов выводится порциями по 24 записи, серверная
  пагинация системных предметов и заклинаний сохранена.
- Школы, типы урона, свойства оружия, известные обозначения времени,
  спасбросков и дистанций отображаются по-русски. Неизвестные значения и
  свободные формулировки условий/правил сохраняются дословно. Словарь работает
  только при отображении, значения запросов и сохранения не переводятся.
- Используются существующие иконки и fallback. Новых BG3-ассетов нет.

## Проверка

- 22 целевых frontend-теста: `npm exec -- vitest run resources/js/compendium
resources/js/rpg/itemGameplay.test.tsx` — PASS.
- TypeScript и production build — PASS. Остались прежние предупреждения Vite
  о `divider.png` и размере dice chunk; они не относятся к библиотекам.
- ESLint и Prettier для изменённых frontend/QA-файлов — PASS.
- `npm run test:content-ux` — пять браузерных сценариев PASS, включая поиск →
  просмотр → независимая копия → редактирование → повторное открытие, ошибки,
  загрузку, пустую выдачу, fallback, клавиатуру и адаптивность. Перед сценарием
  проверяется API-проекция на SQLite `:memory:`: 1 тест / 36 assertions.
- Визуальный набор: 15 системных API-фикстур + 15 пользовательских вариантов
  только в памяти браузера. Всего 15 предметов и 15 заклинаний: восемь школ,
  круги 0–9, пять поддерживаемых редкостей, оружие, броня, щиты, расходники,
  боеприпасы, особые предметы, ритуалы, концентрация, длинные названия и
  отсутствующие иконки. Проверены все 30 Inspector, а также коллекция из
  150 предметов, переход страниц и поиск по всей коллекции.
- Browser QA: desktop 1720×1280 / 1512×1080, tablet 900 px, mobile 390×844;
  проверены отсутствие горизонтального переполнения, прокрутка Inspector,
  доступность действий и возврат фокуса.
- Нативный Laravel с PHP Open Server и изолированной MySQL на
  `http://localhost:8092`: существующие GM и Player в отдельных контекстах,
  desktop/mobile — PASS. Проверены системный каталог, поиск Shield,
  фильтры школы/круга и просмотр Fireball. Все API-мутации в этом smoke
  заблокированы; копирование проверялось в сценарии с API-фикстурами.
- Контрольные суммы данных десяти таблиц (включая migrations, compendium,
  library_items, item_definitions, inventory_items, characters, scenes, users)
  до/после нативного smoke совпали для исходной и изолированной БД.
