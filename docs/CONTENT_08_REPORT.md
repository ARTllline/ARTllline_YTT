Пак **установлен на localhost:8090**. Из 755 доступных системных предметов и
заклинаний 638 получили иконки; в существующие Assets добавлен 481 уникальный PNG.

Из 117 пропусков: 61 `reviewed_doubtful`/неподтверждённая связь и 56 записей без
изображения. Они сохраняют штатную заглушку. Проверенные визуальные fallback
допущены как иллюстрации, без заявления об идентичности игровых сущностей BG3/SRD.
Межсистемные `item_candidate`/`spell_candidate` не используются.

## Подключение

```powershell
# Проверка без записи:
php artisan compendium:visual-pack 'B:\BG3-Assets-Work\Output\Unified-DnD-Library'
# Установка / безопасный повтор:
php artisan compendium:visual-pack 'B:\BG3-Assets-Work\Output\Unified-DnD-Library' --apply
# Отключение привязок; изображения существующих копий сохраняются:
php artisan compendium:visual-pack --detach --apply
```

На другой установке сначала применить обычную миграцию
`2026_11_13_090000_create_compendium_visuals.php`. Пак необязателен: без него
работают прежние заглушки. Записей Compendium команда не создаёт и не обновляет.

Связь проходит через точный `content.source_id` и `stable_version_id`; для старых
API-записей — через upstream index, URL, редакцию и тип. Дополнительно проверяются
метаданные источника, разрешение browse, завершённый визуальный review,
`record.icon → detail.assets → index.icon`, SHA-256 и декодирование PNG.
Несогласованные/повторные ID, подмена пути, повреждение PNG и конфликт существующей
привязки останавливают установку. При изменении checksum записи её привязка не
выдаётся потребителям. Полная предварительная проверка предшествует транзакции;
повторная проверка выполняется под блокировкой. Ошибка установки откатывает новые
строки и созданные файлы, пока удерживается блокировка установки.

Изображения находятся только в приватном диске `campaigns`:
`storage/app/campaigns-private/local-visual/`. Это существующие Asset с уникальным
`builtin_key=local-visual:<sha256>`; пользователь не может заменить или удалить их.
Доступ предоставляется аутентифицированным пользователям штатной AssetPolicy.
Частные пользовательские Assets по-прежнему защищены своими правами.
Папка storage игнорируется Git. В frontend/build находятся только ссылки на API;
извлечённые изображения и исходный экспорт в Git/распространяемую сборку не добавлены.

Привязки хранятся отдельно от `raw_data`/`normalized_data`. Новые библиотечные и
игровые копии получают штатный `asset:<id>`. Прежние копии не обновляются задним
числом. Единый RpgIcon использует lazy/async thumbnails с обработкой ошибки:
Item/Spell Library, Inspector, инвентарь, экипировка, книга заклинаний и drag preview
используют существующие пути отображения. В старом Compendium добавлены изображения
в строки и заголовок записи, без изменения структуры библиотеки.
