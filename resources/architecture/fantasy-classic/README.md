# Fantasy Classic — Stone & Timber

Встроенный набор YTT v1. В [манифесте](manifest.json) перечислены 19 материалов,
имена исходных PNG и SHA-256 исходников и готовых WebP.

| Поверхность | Состав |
| --- | --- |
| Стены | Гранитный тёс, грубая кладка, красный кирпич, дубовый брус, известка и балки, обветренные руины |
| Полы | Медовые доски, тёмный паркет, сланцевые плиты, мшёный плитняк, терракота, известняковая плитка |
| Двери | Дуб с ковкой, подъёмная решётка, орех с заклёпками, резной дуб с бронзой |
| Окна | Свинцовый витраж в дубе, каменное окно с решёткой, ромбовый витраж с латунью |

## Форматы

- Стены используют полосу 512 × 128 с повтором вдоль стены. После обрезки
  внешних полей сведены противоположные края по горизонтали.
- Полы используют плитку 512 × 512 с согласованными краями по обеим осям.
- Двери используют прозрачный атлас 512 × 192. Верхняя строка содержит закрытую
  дверь, нижняя содержит те же косяки с прозрачным проёмом. В открытом состоянии
  распашное полотно берётся из центральной части верхней строки и вращается
  вокруг петли. У подъёмной решётки остаются только косяки.
- Окна используют прозрачный спрайт 512 × 128 с рамой, подоконником и
  витражом или решёткой.

## Установка и версии

```powershell
php artisan migrate
php artisan ytt:install-fantasy-classic
```

Повтор команды сохраняет ID встроенных записей. Материал и его версия
регистрируются отдельно. Для обновления арта добавьте новую версию пакета с
неизменными ключами материалов. Размещённые поверхности продолжают ссылаться
на ранее сохранённую версию.

В Global Assets выберите «Архитектура», а в Material Library или Build выполните
поиск по названию набора или поверхности. Копия материала принадлежит GM, её
можно переименовать, заменить текстуру или изменить доступные параметры.
