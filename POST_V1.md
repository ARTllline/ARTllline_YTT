# After V1

Keep these outside the stabilization release. Prioritize evidence from real sessions.

1. Run multi-hour sessions on intended VPS and real Safari/tablet devices; address
   measured interaction, reconnection and GPU problems before expanding features.
2. Bound long fog histories with a privacy-safe checkpoint format if measured
   hydration cost warrants it. Add storage reconciliation/GC with a dry run.
3. Broaden safe editor Undo only with precise inverse contracts; consider durable
   pending-edit recovery and accessible alternatives to pointer-only editing.
4. Improve preparation search, command palette and import/export once their workflow
   is validated with campaign data. Retain portable, standalone deployment.
5. Treat LOS/walls/lighting as a separately designed subsystem. Rules/dice engines,
   character builders, macros/DSL, Story integration, spatial audio, cloud storage,
   voice/video and a plugin ecosystem need independent scope and acceptance.

No implementation of these systems is included in Task 12.
